AGENTS.md задаёт маршрут по задаче. Подробные правила читаются по необходимости:

- 01_Ведение_игры.md — канон, сообщения, сцены и полный цикл хода.
- 02_Портреты_персонажей.md — генерация и закрепление портретов.
- 03_Обзор_и_простой_режим.md — работа обычными сообщениями.
- 04_Экспорт_MD_в_одну_папку.md — экспорт только по прямой просьбе.
- 05_Активы_персонажей.md — войска, предметы, владения и визуалы активов.
- 06_Память_и_связи.md — источники истины, схемы данных, контекст и проверки.

Пользователь не должен подготавливать контекст вручную. Не читай все инструкции и всю хронику при каждом ходе.
Новые правила добавляй в профильный документ. Не дублируй постоянные списки команд и номера активной главы: они определяются по файлам и инструментам.
