# Экспорт Markdown-файлов в одну папку

---
type: maintenance_instruction
status: active
canon_level: support
updated_real_date: 2026-10-24
---

Эта процедура нужна только если пользователь прямо попросил собрать все Markdown-файлы в плоский архив. В обычной работе ее не запускать.

## Правила

1. Найди все существующие файлы с расширением `.md` во всех папках проекта.
2. Создай в корне проекта папку `Все_MD_файлы`.
3. Скопируй туда все найденные `.md` файлы в один плоский список, без вложенных папок.
4. Не перемещай и не удаляй исходные файлы, только копируй.
5. Не включай в поиск файлы, которые уже лежат внутри `Все_MD_файлы`, и служебные папки `.git`, `.wmma` (рабочие копии ходов и тестов), `.build` (сборки) и `.regnum-backup` (резервные копии мира Regnum).
6. Если у разных файлов одинаковые имена, используй имя на основе исходного пути, заменяя символы папок на `__`.
7. После копирования проверь, что в папке `Все_MD_файлы` нет вложенных папок и что количество скопированных файлов совпадает с количеством найденных исходных `.md`.

Папка `Все_MD_файлы` является временным экспортом и игнорируется Git. Не используй ее как источник канона.

## Команда PowerShell

```powershell
$ErrorActionPreference = 'Stop'

$root = (Get-Location).Path.TrimEnd('\')
$dest = Join-Path $root 'Все_MD_файлы'

New-Item -ItemType Directory -Force -Path $dest | Out-Null

$destResolved = (Resolve-Path -LiteralPath $dest).Path.TrimEnd('\')

# Папка экспорта и служебные папки не обходятся: Git, рабочие копии ходов и тестов,
# сборки и резервные копии мира Regnum.
$excluded = @('.git', '.wmma', '.build', '.regnum-backup')
$found = New-Object 'System.Collections.Generic.List[System.IO.FileInfo]'
$folders = New-Object 'System.Collections.Generic.Stack[string]'
$folders.Push($root)

while ($folders.Count -gt 0) {
    foreach ($item in Get-ChildItem -LiteralPath $folders.Pop() -Force) {
        if ($item.PSIsContainer) {
            if ($excluded -contains $item.Name -or $item.FullName.TrimEnd('\').Equals($destResolved, [System.StringComparison]::OrdinalIgnoreCase)) {
                continue
            }

            $folders.Push($item.FullName)
        } elseif ($item.Extension -eq '.md') {
            $found.Add($item)
        }
    }
}

$files = @($found | Sort-Object FullName)

$used = New-Object 'System.Collections.Generic.HashSet[string]' ([System.StringComparer]::OrdinalIgnoreCase)
$copied = 0
$renamed = 0

foreach ($file in $files) {
    $name = $file.Name

    if (-not $used.Add($name)) {
        $relative = $file.FullName

        if ($relative.StartsWith($root + '\', [System.StringComparison]::OrdinalIgnoreCase)) {
            $relative = $relative.Substring($root.Length + 1)
        }

        $name = ($relative -replace '[\\/:*?"<>|]', '__')
        $renamed++
        $candidate = $name
        $i = 2

        while (-not $used.Add($candidate)) {
            $stem = [System.IO.Path]::GetFileNameWithoutExtension($name)
            $candidate = "$stem`_$i.md"
            $i++
        }

        $name = $candidate
    }

    Copy-Item -LiteralPath $file.FullName -Destination (Join-Path $dest $name) -Force
    $copied++
}

$mdCount = (Get-ChildItem -LiteralPath $dest -File -Filter '*.md' | Measure-Object).Count
$dirCount = (Get-ChildItem -LiteralPath $dest -Directory | Measure-Object).Count

[pscustomobject]@{
    Destination = $dest
    MarkdownFilesFound = $files.Count
    MarkdownFilesCopied = $copied
    MarkdownFilesInDestination = $mdCount
    SubfoldersInDestination = $dirCount
    RenamedForFilenameCollisions = $renamed
} | Format-List
```
