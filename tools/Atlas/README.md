# Atlas — редактор карт Windows

---

Нативное приложение на C++20: Win32, Direct2D, DirectWrite, Windows Imaging Component. WPF, .NET, браузер и сторонние пакеты приложению не нужны. Стандартная библиотека C++ включена в сборку; используются системные DLL Windows.

## Запуск

Открой [Открыть_Атлас.cmd](../../Открыть_Атлас.cmd) из корня проекта, bin/Atlas.exe или «Запустить_Атлас.cmd» из этой папки. В репозитории редактор автоматически открывает «12_Карты/Карта_мира_Объекты». В переносимом комплекте папка «Карта» лежит рядом с исполняемым файлом.

Готовые Atlas.exe и Atlas.Cli.exe включены в Git: после скачивания проекта или git pull редактор запускается без компилятора и пересборки. Изменения карты, глав и карточек не требуют сборки приложения. Пересобирается только изменённый код редактора или встроенные шаблоны; тогда вместе с исходниками обновляются проверенные EXE. Файлы .wmma и .atlas остаются локальными, переносимый ZIP создаётся отдельно командой package.ps1.

Рабочая карта восстановлена в геометрические объекты: 47 территорий, 1 278 горных значков, 304 маркера поселений, 251 распознанная подпись и 48 подписей государств. В скрытом архиве находятся 24 заметки исходного PDN и 59 участков торговых путей. После отделения суши: 2 020 объектов, 42 373 узла и 7 152 участка. Растровых слоёв в этой карте нет; SVG-экспорт не содержит встроенных картинок.

Интерфейс построен по утверждённому минималистичному концепту: карта занимает рабочее окно, слева плавающий ряд иконок, справа раскрываются слои, библиотека или свойства. Названия инструментов и клавиши появляются при наведении. Ctrl+F открывает поиск стран, F2 — свойства выбранного объекта. Все прежние команды доступны через меню ☰ и «…». В библиотеке 17 векторных шаблонов; горы, корабли, флот и гавань получили новое оформление.

Сверху слева всегда доступны три режима: «Границы», «Суша», «Объекты». В режиме «Границы» V, K и N выбирают только политические контуры: клик по линии показывает контрольные точки, перетаскивание точки меняет два соседних отрезка. Остальной контур сохраняется. Двойной клик или + добавляет точку, Delete удаляет выбранную; Shift ограничивает движение осью. Концевые стыки и соединения нескольких границ защищены от удаления. Enter или «Готово» завершают рисование, Esc отменяет жест; Ctrl+Z/Y отменяют и повторяют действие.

J создаёт землю и редактирует берег, P создаёт государство с разделением занятой площади соседей. Суша имеет отдельные координаты: удаление государства оставляет нейтральную землю. Границы могут проходить в море; кнопка «Море» включает полупрозрачную морскую заливку выбранных государств. Она не передвигает берег. Без неё политическая заливка ограничена сушей, но контрольные точки по-прежнему перемещаются свободно. Политические линии всегда рисуются поверх гор, городов, подписей и предпросмотра перемещения. [Контрольные точки](Примеры/Контрольные_точки.png).

Подписи мелких поселений появляются при достаточном масштабе; перекрывающиеся названия стран разрежаются в окне. «Вид → Показать / скрыть подписи карты» управляет их отображением. Версии открываются кнопкой снизу слева; список прокручивается колесом.

Геометрия — приближённая реконструкция присланного изображения, а не новое подтверждение географии канона. Мелкие подписи и текст архивных заметок имеют отметку ocr_unverified; ошибки распознавания требуют сверки. Схема гильдии с четырьмя процентными подписями и границы регионов также перенесены в скрытый архив. Техническое описание и повторяемый процесс находятся в [reconstruction/README.md](reconstruction/README.md).

Другой проект можно открыть через «Файл → Открыть / импортировать». Поддерживаются map.json, PDN3 и обычные растровые изображения. Импорт выполняется в новую выбранную папку и не перезаписывает исходник.

Если переносимый комплект распакован вне репозитория, выбери «Файл → Выбрать папку кампании». Это подключает карточки и сцены из существующего проекта; копировать всю хронику в комплект не нужно.

bin/Atlas.Cli.exe — тот же движок для командной строки. Графический редактор не открывает консольное окно.

Камера и зум используют фоновый поток: окно перемещает готовый обзор, а точная детализация поступает отдельно. [Устройство и проверки](performance/land-camera.md).

Предыдущая оптимизация отрисовки: повторные кадры используют кеш вида в памяти, колесо получает быстрый промежуточный кадр и точную перерисовку после остановки. Данные карты сохраняются в векторном формате. [Замеры и устройство кеширования](performance/README.md).

## Работа на карте

| Действие | Управление |
| --- | --- |
| Режим выбора | «Границы» / «Суша» / «Объекты»; V — выбор внутри режима |
| Суша и острова | J; нарисовать землю или захватить береговую точку |
| Государство | P; занять область с разделением территории соседей; «Море» разрешает морскую заливку |
| Точки границы | K; клик по линии, затем потянуть круглый маркер; Shift — движение по оси |
| Добавить / удалить точку | Двойной клик по линии или +; Delete для выбранной точки |
| Территория / маршрут / река / зона | P / R / U / Z; клики задают узлы; Enter или двойной клик завершает |
| Кисть / ластик | B / E; на доступном растровом слое меняют пиксели, на слое объектов — линии и объекты |
| Символ / подпись | S / T; выбрать символ в библиотеке, поставить на карте |
| Обводка по цвету | W; выбрать растровый слой, нажать внутри области, затем дать название и связь |
| Прямоугольник / лассо | G / L; лассо и рамка также ограничивают растровую кисть и заливку |
| Заливка / пипетка | F / I; заливка работает с объектами и доступными растровыми слоями |
| Измерение | M; расстояние показывается в пикселях карты, не в выдуманных километрах |
| Масштаб | Колесо; Home — весь лист |
| Перемещение полотна | Пробел, средняя кнопка или H |
| Отмена незавершённого действия | Esc; также снимает область выделения |
| Сохранение / отмена / повтор | Ctrl+S / Ctrl+Z / Ctrl+Y |
| Копирование / вставка / дубликат объектов | Ctrl+C / Ctrl+V / Ctrl+D |
| Скрыть панели | Tab |

В правой панели находятся свойства, связь с карточкой и слои. Границы закреплены сверху; порядок заливок регулируется отдельно. Первый значок строки — глаз, второй — замок. Клик по названию слоя включает выбор только этого слоя и подходящий режим. Под переключателем режимов появляется плашка «Только слой»: клик по ней или по стрелке в панели снимает изоляцию. Архивные слои раскрываются кнопкой «Архив». Слои прокручиваются колесом. Водная сеть заблокирована от случайного выбора. Новое рисование автоматически использует видимый слой. При отдельном импорте PDN его растровые слои заблокированы; изменённые пиксели сохраняются в отдельной PNG-ревизии, исходный PDN остаётся целым.

«Оформление» меняет параметры объектов. Для выбранного символа можно сохранить собственный шаблон с текущими параметрами. Определения символов — обычные массивы векторных линий в данных карты; их также удобно изменять кодом.

Общие границы состоят из участков ARC и узлов NODE. Привязка при рисовании использует существующие узлы. Пространственная близость двух независимых обводок сама по себе не создаёт подтверждённого политического соседства.

«Карта → Объединить территории» объединяет выбранные замкнутые области. При вычитании исходной считается первая область по ID, показанная первой в свойствах выделения. Результат получает собственное имя и не наследует политическую принадлежность автоматически.

## История

Ctrl+S сохраняет рабочую копию. Автосохранение выполняется каждые 15 секунд при наличии изменений; восстановление доступно в меню «Файл».

«Сохранить версию» создаёт независимый снимок с названием, статусом и необязательной привязкой к существующей сцене. Глава, ветка и источники берутся из выбранной сцены. Точный календарь не выдумывается; положение задаётся как «до» или «после» сцены.

«Сравнить» показывает снимок и рабочее состояние рядом. В меню «Версии» доступны список изменений и создание рабочей копии выбранного снимка. Сам снимок при восстановлении не изменяется. Сохранение в новую папку переносит историю и её растровые исходники.

Редактор проверяет хеш открытого файла перед сохранением. Если другой редактор или агент уже изменил карту, автоматического затирания не будет: можно загрузить новое состояние или сохранить свои изменения отдельно.

## Формат и работа из кода

Текущее состояние хранится в одном детерминированном UTF-8 JSON-файле map.json. Это позволяет заменять документ атомарно. Коллекции features, nodes, arcs и symbols организованы по устойчивым ID; имя файла карточки и отображаемая подпись не служат ключами. Неизвестные дополнительные поля сохраняются при чтении и записи.

В отличие от первоначального предложения с отдельным файлом на каждый объект, текущий формат использует один файл состояния. Различия остаются читаемыми в Git, а движок diff возвращает изменения по объектам и узлам. Отдельные файлы используются для снимков и растровых ревизий.

Объект MAPOBJ может ссылаться на LOC, CHAR или ASSET через entity_id. Узел содержит координаты, участок — список узлов, территория — ориентированные ссылки на участки. Внутренние отверстия и раздельные части сохраняются в rings. Растровая подложка имеет отдельный тип и не выдаётся за распознанные объекты.

Примеры из корня репозитория:

```powershell
& './tools/Atlas/bin/Atlas.Cli.exe' inspect './12_Карты/Карта_мира_Объекты' --json
& './tools/Atlas/bin/Atlas.Cli.exe' validate './12_Карты/Карта_мира_Объекты' --project '.'
& './tools/Atlas/bin/Atlas.Cli.exe' apply './12_Карты/Карта_мира_Объекты' --patch './изменение.json' --dry-run
& './tools/Atlas/bin/Atlas.Cli.exe' snapshot './12_Карты/Карта_мира_Объекты' --name 'Название версии' --scene SCENE-0039 --project '.'
& './tools/Atlas/bin/Atlas.Cli.exe' render './12_Карты/Карта_мира_Объекты' --output './карта.png'
```

Пример сцены в команде не является назначением сюжетной даты импортированной карте. Вместо SCENE-0039 выбирается событие, действительно объясняющее нужный момент.

Патч содержит expected_hash из inspect и массив operations. Поддержаны move_control (id участка, node_id, position, allow_sea), insert_control (id, position, allow_sea), delete_control (id, node_id), move_node, а также прежняя операция move_border (id участка, grab, delta, radius) для совместимости, set_feature, add_feature, delete_feature, put_node, put_arc, put_symbol, set_layer, set_anchor. Сначала выполняется --dry-run; затем тот же патч применяется без этого флага. Проверка хеша и атомарная запись защищают от параллельных правок.

В CLI также доступны trace — обводка растровой области по координатам, diff — различия по ID, restore — рабочая копия снимка, pdn-info — структура PDN и проверка пикселей. Полный синтаксис показывает команда help.

## Экспорт и границы применимости

PNG использует тот же движок отрисовки, что и карта в окне. Обычный SVG сохраняет ID и векторные контуры; исходные растровые слои встраиваются изображениями. При сложном смешивании или чередовании растров и векторов с темой «Атлас» SVG сводится в изображение для точного сохранения вида; это отмечено внутри SVG. Есть печать через стандартный диалог Windows.

PDN-импорт поддерживает проверенную структуру PDN3 с отложенными BGRA-блоками и обычные 14 режимов смешивания Paint.NET. Неподдерживаемая структура отвергается сообщением. Сохранение выполняется в проект Atlas, экспорт обратно в изменённый PDN не реализован. Исходный PDN сохраняется без изменения байтов.

Предел полотна — 64 миллиона пикселей и 16384 пикселя по каждой стороне. Скрытые PDN-слои раскрываются по запросу. Для сложного смешивания используется точное программное сведение с кэшированием результата; такая операция тяжелее обычного просмотра слоёв.

Персонажный экспорт в CLI допускает только PNG. GM-объекты исключаются. Для public необходимы evidence_ids; для restricted — запись known_to и knowledge_evidence с character_id, evidence_ids и basis. Эти поля заполняются по основаниям кампании, а не по предположениям редактора. По умолчанию импортированные растры и новые объекты имеют видимость gm. Редактор не определяет истинность литературного утверждения и не заменяет Получить_контекст с Audience character.

## Сборка и проверка

```powershell
& './tools/Atlas/build.ps1' -Test
```

Скрипт использует закреплённый переносимый LLVM-MinGW с проверкой SHA-256. Компилятор располагается в игнорируемой служебной папке .wmma; полученный exe от него не зависит. Также предусмотрен CMake-проект для C++20 и Windows SDK, включая MSVC. Пакетов через NuGet, vcpkg или Conan нет. Шаблоны symbols.json включаются в exe при сборке; Python редактору не требуется.

Нативный self-test выполняет 129 проверок: JSON, повреждённые данные, общий участок двух стран, отмена/повтор, сохранение, снимки, конфликты записи, восстановление, обводка с отверстиями, PNG, SVG и все 32 слоя присланного PDN. Он также проверяет выбор страны по подписи, независимый выбор текста, реальные общие границы, групповое перемещение, выбор видимого слоя и отсутствие изображений в SVG объектной карты. Полный проект дополнительно проверяется штатным Завершить_ход.

Atlas 4 проверен мышью на отдельной копии карты: масштабирование, выбор линии, перемещение контрольной точки за берег, отмена, панель слоёв и изоляция политического слоя. Программные проверки дополнительно покрывают общий участок двух государств, морское государство без суши, блокировки, верхний проход границ и подавление старой линии при перетаскивании. Замеры и ограничения: [контрольные точки и камера](performance/control-points.md).
