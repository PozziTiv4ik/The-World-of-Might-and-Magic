# Архив канона

---
type: canon_archive_readme
status: active
canon_level: support
---

Здесь хранятся завершенные главы и события, которые больше нельзя менять по смыслу.

## Правило

Если глава попала сюда, она становится каноном.

Архивные копии, файлы закрытых глав и их сцены защищены контрольными суммами в `10_Обслуживание/Миграция_v2.json`. Опечатку или формат исправляют только вместе с командой `tools/Обновить_защиту_канона.ps1 -Path <файл> -Reason <причина>`: она записывает новый хеш, прежний хеш, дату и причину в журнал манифеста. Смысл решений, событий и последствий меняется только по принятой реткон-заявке (`02_Лор/02_Канон_и_заморозка.md`), и её ID указывается в причине.

## Куда класть завершенные главы

`06_Архив_канона/Завершенные_главы`

## Что добавлять в конец завершенной главы

```text
Итог:
Главные решения:
Последствия:
Открытые крючки:
Связанные персонажи:
Связанные локации:
```
