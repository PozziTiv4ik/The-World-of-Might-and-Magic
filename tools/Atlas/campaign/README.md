# Сюжетная карта кампании

Профиль [profile.py](profile.py) задаёт конкретные координаты 106 мест, порядок всех 120 сцен, позиции героев, изменения контроля и прежние государства юга. Сцены и карточки остаются литературными источниками; расположение на карте является авторской картографией по поручению пользователя.

[generate.py](generate.py) читает источники из текущего проекта и работает через Atlas.Cli.exe: inspect → apply --dry-run → apply → snapshot. Геометрические разделения и объединения проходят claim-country с проверкой хеша. Каждый снимок получает сцену, главу, относительную дату, порядок и короткое описание. Дополнительно создаются четыре итога глав. Два прежних снимка сохраняются с прежними байтами.

```powershell
python -X utf8 './tools/Atlas/campaign/generate.py'
```

Запускать в транзакционной рабочей копии. Для другого расположения доступны --project, --map и --cli. Профиль должен охватывать все сцены ровно один раз, сохранять порядок внутри каждой ветки и содержать координаты всех карточек мест. Проверки выполняются до записи.

history/campaign.json сохраняет ход сборки, хеш профиля и исходных сцен, ID созданных версий. Повторный запуск продолжает незавершённую сборку или проверяет завершённую без перезаписи версий. Изменение источников требует новой цепочки на копии карты. Обычное продолжение игры записывается новыми версиями через CLI или редактор; заново собирать главы не нужно.

Политические территории Шахибдии, Шамат-Ракшаса, Кланов Закона и Обсидианового королевства выделяются внутри контура поздней Империи Вечного Солнца. Их восстановленная компоновка не меняет текст глав. Реальные объединения происходят после SCENE-0011, SCENE-0050 и SCENE-0104.

Маркеры показывают последнее место, установленное соответствующей сценой. Пунктир соединяет такие позиции, а не изображает точный путь по каждой дороге. Сон не перемещает персонажа. Разрешение на штаб в Андрианаполисе отличается от действующего штаба Цитадели Ночи; ложное известие о смерти не удаляет героя. Явные связи after/overlaps сохранены в данных кампании; дополнительное чередование веток служит порядком чтения Atlas.

Слои мест, путей, героев и событий можно включать и править отдельно. В архиве доступны исходные OCR-объекты. Чтобы менять положение имени героя вручную, поставь auto_label=false и измени label_offset через обычный патч.
