Этот каталог хранит технические сведения, не сюжет.

Миграция_v2.json — защитный манифест: исходный Git-коммит миграции, контрольные суммы закрытого канона (файлы закрытых глав, их архивные копии и сцены закрытых глав; у защищённых позже — дата и причина защиты) и сохранённых исторических текстов, включая прежние тексты объединённых карточек. Исторические документы проверяются после нормализации переносов строк, закрытый канон — по исходным байтам. Новые байты защищённого файла принимает только `tools/Обновить_защиту_канона.ps1` с причиной; журнал `amendments` хранит дату, прежний и новый хеш. Закрыть_главу и Объединить_сущности ведут манифест сами.

Генерируемые представления: Покрытие_данных.md и Покрытие_данных.json (`tools/Собрать_аудит_данных.ps1`), Очередь_вопросов.md (`tools/Собрать_память.ps1`).

Действующий отчёт — Аудит_2026-10-23.md. Аудит_2026-09-12.md, Рефакторинг_2026-09-12.md и Рефакторинг_2026-09-22.md — исторические отчёты (`status: historical`): упомянутые в них команды и схема CI могли измениться. Аудит_знаний_2026-09-12.json — историческое приложение к Аудит_2026-09-12.md (изменения круга знающих при миграции); его ничто не генерирует. Прежний Метрики_v2.json удалён: его числа сохранены в Рефакторинг_2026-09-12.md, а ссылок на файл не было.

Нормальная работа выполняется средствами PowerShell 7; Python не нужен. Одноразовые сценарии миграции v2 выполнены и удалены из рабочего дерева; они сохранены в истории Git (коммит 9f0c693). Пересборки выполняются через Завершить_ход.
