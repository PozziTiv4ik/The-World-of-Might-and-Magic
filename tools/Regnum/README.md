# Regnum — редактор мира Меча и Магии

---
type: tool_documentation
status: active
canon_level: support
updated_real_date: 2026-10-03
---

Regnum — нативный редактор стратегической карты мира: провинции, государства, торговые гильдии, войска и флот, экономика, постройки, технологии, модификаторы и ходы. Написан на C++20 только со стандартной библиотекой: окно, отрисовка, шрифты, интерфейс, PNG/JPEG, zip и JSON — собственные. Работает на Windows, Linux и macOS без установки.

## Запуск

| Система | Как открыть |
| --- | --- |
| Windows | Открыть_Regnum.cmd в корне проекта — сразу открывает мир из 12_Карты (перетащенную на него папку мира или файл .regnum — их); tools/Regnum/bin/windows/regnum.exe — экран запуска |
| Linux | tools/Regnum/regnum.sh (готовая сборка — bin/linux-x64; при отсутствии собирается системным компилятором) |
| macOS | tools/Regnum/Regnum.command (готовая сборка — bin/macos-arm64 или bin/macos-x64) |

Мир можно открыть сразу: передайте папку мира или файл .regnum в командной строке либо перетащите их в окно. Основной мир проекта — 12_Карты/Мир_Меча_и_Магии.

## Экран

- **Верхняя панель:** название мира и состояние сохранения, режимы карты (клавиши 1–9), отмена и повтор, поиск и команды (Ctrl+K), номер хода и кнопка «Завершить ход».
- **Левая лента:** провинции (Ctrl+1), государства (Ctrl+2), торговые гильдии (Ctrl+3), персонажи (Ctrl+4), войска и флот (Ctrl+5), модификаторы (Ctrl+8), хроника (Ctrl+9), торговля, справочники, дерево построек.
- **Панель инструментов карты:** выбор (V), перемещение (H), галочка «Правка границ» (E), при правке — инструменты провинций; «Правка карты» (T) — инструменты суши, берега, вод, гор, замков и башен; новое войско (A), новый флот (Shift+A), торговый маршрут (R).
- **Правый инспектор:** сведения о выбранной провинции, фракции, войске, маршруте или персонаже — значки-вкладки с подсказками.
- **Внизу:** строка состояния, легенда режима (L), масштаб и мини-карта (M).

Всё, что меняет мир, отменяется Ctrl+Z и повторяется Ctrl+Y. Подсказка есть у каждого значка, полный список сочетаний — F1.

## Провинции

Карта нарисована кодом: береговая линия, островки, реки и озёра, стены, горы, замки и башни — объекты, которые редактор рисует при любом масштабе (картинка карты не загружается). Образец — tools/Regnum/assets/basemap/map.json: объекты разобраны из исходного изображения 8000 × 4500 командой regnum-cli build-map и расставлены там же, где на нём; при масштабе 1 карта повторяет исходник (средняя ошибка меньше 1 из 255 на канал), при приближении знаки остаются чёткими. Всё на карте правится (раздел «Правка карты»). Заливка провинций проходит под знаками и реками.

Галочка «Правка границ» (E, значок замка) переключает режим для всех провинций сразу. При выключенной правке (замок закрыт) границы и области закреплены: щелчок по провинции открывает её сведения, удалить провинцию (Delete, меню) нельзя. При включённой правке (замок открыт) щелчок открывает границы выбранной провинции. На прошлом ходу (только просмотр) режим правки недоступен:

| Действие | Как |
| --- | --- |
| Сдвинуть точку или узел | Перетащить. Общая граница меняет обе соседние провинции: одна растёт, другая уменьшается. Пересечения запрещены |
| Добавить или удалить точку | Двойной щелчок по границе; Delete или правая кнопка |
| Сдвинуть стык с берегом | Перетащить ромб — он скользит вдоль берега |
| Новая провинция (P) | Щёлкать вершины или вести мышью; Enter — готово. Сухопутная провинция сама прилипает к берегу |
| Расширить (G) / вырезать (X) | То же для выбранной провинции |
| Заливка (U) | Щелчок по свободной суше или острову; Shift — добавить к выбранной |
| Нож (K) | Линия через провинцию делит её на две |
| Объединить (J) / удалить (D) | Щелчок по соседней или по самой провинции, с подтверждением |

Сведения о провинции: владелец, лорд, столица, величина и тип города (слоты построек), галочка «Морская провинция» (скрывает сведения), оккупация со штриховкой цветом оккупанта, население по расам, культура, религия, довольство и вероятность восстания, ресурс и добыча, базовая и текущая торговая ценность, налоги, влияние и штабы гильдий, модификаторы, гарнизон, постройки.

## Правка карты

Кнопка «Правка карты» (T, гора с карандашом) включает правку самой карты: суши и берега, озёр и рек, островков, стен, гор, замков и башен (правка границ при этом выключается, и наоборот). Каждое действие отменяется Ctrl+Z:

| Инструмент | Что делает |
| --- | --- |
| Объекты карты (O) | Щелчок — гора, замок, башня, озеро, река, стена или островок (сведения — в инспекторе); Shift+щелчок и рамка — несколько знаков; перетаскивание — перенести; стрелки — сдвиг (Shift — на 10); Delete — удалить. У выбранной фигуры — её точки: тянуть, двойной щелчок по контуру — новая, Delete или правая кнопка — удалить |
| Знак (S) | Щелчок — гора (два рисунка вершины), крупная гора, замок или башня; протяжка — кисть: знаки вдоль пути (горный хребет); вид и размер — на панели сверху |
| Озеро (W) | Контур щелчками или от руки, Enter — готово |
| Река (Shift+W), стена (Q) | Линия заданной ширины |
| Добавить сушу (N), убрать сушу (Shift+N) | Контур: море внутри станет сушей (новый остров, мыс) или суша — морем (залив, пролив); провинция другого типа теряет попавшую площадь, провинция без области удаляется |
| Берег (Y) | Точки береговой линии у указателя: тянуть, двойной щелчок по берегу — новая точка, Delete — удалить; стык с границей провинции двигает и её конец |

В инспекторе знака — вид и рисунок, размер, положение, порядок наложения («Выше соседей», «Ниже»); у стены и реки — ширина, у стены — пунктир. Новый или перенесённый знак встаёт в порядок отрисовки по соседям: за знаками, которые стоят ниже по карте.

Пока карту мира не правили, мир показывает объекты базовой карты. Первая правка переносит их в мир (data/map.json папки мира) вместе с самой правкой — одним шагом отмены; дальше у мира своя карта, а базовая остаётся образцом для новых миров. Берег — часть геометрии провинций (data/geo.json). Мини-карта и миниатюра мира догоняют правку через долю секунды.

## Государства и гильдии

Списки в левой ленте, кнопка «+» создаёт фракцию. Государство: флаг (конструктор узоров и эмблем или своё изображение), цвет, культура, форма правления, правитель и титул, совет, провинции и расы, столица, религия, экономика (казна, доходы и расходы, налог, ресурсы, дань и репарации), дипломатия со всеми фракциями (значение −100…+100 и состояние, изменения видны у обеих сторон), герои, модификаторы, войска и флот, технологии, уникальные постройки, торговля, гильдии государства. Гильдия устроена так же, но вместо провинций у неё штабы; государственная гильдия создаётся из панели государства и не меняет государство расположения.

## Войска и флот

Таблицы войск и флота фракции: тип, численность общая, в поле, в резерве, содержание. Войско и флот ставятся на карту инструментами A и Shift+A и получают отряды только из резерва своей фракции. Перетаскивание фигурки на чужое войско ведёт к объединению, союзному войску, объявлению войны или битве — по состоянию отношений. Панель битвы задаёт потери и победителя (сторона без оставшихся отрядов победить не может), а «Отступить» возвращает войско назад без потерь — если потери уже введены, панель предупреждает и переспрашивает. Есть «Разделить», «Расформировать» (отряды возвращаются в резерв) и «Распустить союз».

## Экономика, торговля, постройки, технологии

Формулы — [RULES.md](docs/RULES.md). Торговля — двусторонние сделки разово или «каждый ход» на срок, подарки, дань и репарации. Дерево построек: общее для всех государств и уникальное для каждого (дерево государства показывает и постройки общего дерева — для просмотра, со ссылкой на правку); уровни, стоимость, сроки, модификаторы. Строительство в провинции занимает слоты и списывает ресурсы. Дерево технологий у каждой фракции: связи-зависимости, срок изучения, галочка «изучено», исследование по ходам.

## Модификаторы и справочники

Окно модификаторов (Ctrl+8) задаёт локальные и глобальные эффекты в пределах технического задания. В провинции действуют только локальные эффекты: модификатор лишь с глобальными эффектами провинции не предлагается, а уже добавленный помечен предупреждением. Вкладка «Модификаторы» государства сводит эффекты его модификаторов, изученных технологий и построек. Справочники ведут ресурсы, расы, культуры, религии, формы правления и должности.

## Ход и история

«Завершить ход» (Ctrl+Enter) показывает итог заранее: казну, ресурсы, завершения и предупреждения. Затем запоминается снимок конца хода, выполняется расчёт и запоминается снимок начала следующего хода; снимки записываются в history/ при сохранении мира («Не сохранять» отбрасывает их вместе с миром). Каждое событие хода попадает в хронику (Ctrl+9). «История ходов» позволяет посмотреть любой прошлый ход только для чтения, вернуться к нему или начать текущий ход заново — ровно с того состояния, с которого он начался в текущей ветви; возврат тоже отменяется Ctrl+Z.

## Сохранение

Мир — папка с world.json, data/*.json и history/. Ctrl+S записывает только изменённые файлы атомарно и держит пять резервных копий в .regnum-backup (версии автосохранения — в своей очереди .regnum-backup/auto, они не вытесняют копии ручных сохранений). «Сохранить как» записывает папку или один файл .regnum (zip). Автосохранение идёт каждую минуту в папку данных пользователя и, по настройке, в папку мира. После сбоя редактор предложит восстановить автосохранение. Если файлы мира или архив .regnum изменил кто-то другой (например, агент), редактор спросит, что оставить, а Ctrl+S предложит «Перечитать», «Сохранить с заменой» или «Отмена». Формат описан в [FORMAT.md](docs/FORMAT.md).

## Командная строка

```
regnum-cli validate <мир> [--json] [--strict]     проверка данных и геометрии
regnum-cli inspect <мир> [--json]                 сводка мира (и объекты карты)
regnum-cli convert <откуда> <куда>                папка <-> .regnum
regnum-cli new <папка> --name="Название"          новый мир по базовой карте
regnum-cli build-map <png> <папка>               разобрать изображение карты в объекты (map.json)
```

## Сборка и проверки

`tools/Regnum/build.sh` собирает в Git Bash на Windows и в терминале Linux/macOS: `build.sh --test` запускает все тесты, `build.sh regnum regnum-cli` собирает программы, `build.sh --target linux-x64|linux-arm64|macos-arm64|macos-x64 regnum regnum-cli` собирает для другой системы через Zig. Компиляторы скачиваются в .wmma/toolchains с проверкой SHA-256. `regnum --bench [мир]` открывает окно на несколько секунд и печатает частоту кадров и время фаз кадра при наведении, панораме и масштабировании. Устройство кода — [ARCHITECTURE.md](docs/ARCHITECTURE.md), интерфейс — [UI.md](docs/UI.md).
