# Скорость отрисовки

Актуальная реализация камеры и разделение суши описаны в [land-camera.md](land-camera.md); результаты находятся в camera-background.json. Ниже — история предыдущей оптимизации.

Замер движка на рабочей карте с 2 019 объектами: Direct2D software / WIC, 1280 × 900. Это программный графический буфер без оконного интерфейса и ожидания монитора, а не измеренный FPS окна. После первого кадра измеряются 12 повторов. Данные сохранены в before.jsonl и after.json.

Последующая правка интерфейса и переноса стран описана в [minimal.md](minimal.md); актуальный замер находится в minimal.json. Таблица ниже относится к предыдущей оптимизации кеша.

| Сценарий | Раньше, медиана | После, медиана |
| --- | ---: | ---: |
| Повторный кадр | 88,05 мс | 0,21 мс |
| Перемещение внутри подготовленной области | 89,59 мс | 0,26 мс |
| Движение колеса | 292,70 мс с полной перерисовкой каждого шага | 0,84 мс для промежуточного кадра |
| Точный кадр после остановки колеса | 292,70 мс | 54,24 мс |

Первичная подготовка вида занимает около 70–80 мс. Полная перерисовка после изменения документа в этом программном тесте занимает около 72 мс. Показатели зависят от компьютера, масштаба, области и графического драйвера.

Редактор использует подготовленный вид с запасом за краями экрана. Во время колесного жеста он масштабирует готовый вид и через 120 мс после остановки пересчитывает точное изображение. Кеш существует только в памяти; геометрия и текст сохраняются как объекты, растровая подложка в файл карты не добавляется.

Геометрия символов и стран, стили линий и раскладка текста подготавливаются повторно только по необходимости. Объекты вне видимой области пропускаются. Движения указателя объединяются в кадры с интервалом около 16 мс; последнее событие обрабатывает отдельный таймер. Панорамирование не копирует весь JSON. Сравнение версий использует отдельные кеши.

После замены документа, изменения шаблонов, отмены или повтора вызывается MapRenderer::clear. Во время изменения координат нужен invalidateScene. Потеря графического устройства сбрасывает кеши обоих видов сравнения. Self-test сравнивает кеш и обычную векторную отрисовку по пикселям и проверяет обновление после перемещения, завершения зума, правки узла и шаблона.

Повторить замер из корня проекта:

```powershell
& './tools/Atlas/bin/Atlas.Cli.exe' benchmark './12_Карты/Карта_мира_Объекты'
```

Команда не изменяет карту. Окно исправленной сборки запущено; захват его состояния инструмент computer-use прервал сообщением об Esc. Интерактивный замер мышью не подтверждён.
