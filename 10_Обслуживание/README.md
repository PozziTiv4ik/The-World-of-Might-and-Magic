Этот каталог хранит технические сведения, не сюжет.

Миграция_v2.json фиксирует исходный Git-коммит, контрольные суммы закрытых глав и сохранённых исторических текстов. Исторические документы проверяются после нормализации переносов строк; закрытые главы — по исходным байтам.

Нормальная работа выполняется средствами PowerShell 7; Python не нужен. Одноразовые сценарии миграции v2 выполнены и удалены из рабочего дерева; они сохранены в истории Git (коммит 9f0c693). Пересборки выполняются через Завершить_ход.

Обзор устройства: 00_Инструкции_для_ИИ/06_Память_и_связи.md. Сценарные проверки контекста и восстановления хода: tools/Проверить_сценарии_контекста.ps1.
