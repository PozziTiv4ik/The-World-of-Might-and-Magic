Запусти **Открыть_Атлас.cmd** в корне проекта. Atlas работает на Windows, не требует установки, Python или запущенного сервера. Это нативное приложение C++20 / Win32 / Direct2D.

Текущая карта — **12_Карты/Карта_мира_Объекты**. В неё включена готовая цепочка из 120 сцен, четыре итога глав, 106 связанных с карточками мест и маркеры главных героев. Исходный PDN и прежние версии сохранены. На ранних картах выделены Шахибдия, Шамат-Ракшас, Кланы Закона и Обсидиановое королевство; объединения привязаны к соответствующим сценам. Захваты, освобождения, разрушения и действующие объекты гильдии меняют состояние мест.

## Карта на весь экран

Atlas открывается на карте с компактными плавающими инструментами. **F11** переключает полный экран и обычное окно. Слои, объекты, библиотека значков и свойства открываются по запросу поверх карты. **Esc** закрывает панель или отменяет текущий жест.

Кнопка главы и события сверху, либо **Ctrl+H**, открывает отдельный экран **История карты**. **К карте / Esc** возвращает прежнюю рабочую карту и её масштаб. Сама навигация по истории не подменяет рабочую карту.

## Выбрать событие и редакцию

Хронология — одна горизонтальная линия событий с группировкой по главам. Миниатюры строятся из настоящих снимков карты и загружаются в фоне. Колесо прокручивает события, Ctrl+колесо меняет плотность линии. Стрелки выбирают соседнее событие, Page Up/Down перелистывают экран, Home/End переходят к началу/концу. Линию можно перетаскивать за пустое место.

Кнопка **Все главы** фильтрует главу, лупа / **Ctrl+F** ищет название, место и дату. Меню настроек содержит порядок сюжета, сортировку по дате мира, итоги глав и исходные карты. Сохранённые цепочки — подборки данных; интерфейс не предлагает альтернативных реальностей.

У выбранного события внизу находится отдельная линия **Редакции карты**. В неё входят и прежние исправленные снимки из архива редакций. Выбор v1/v2/v3 меняет предпросмотр этого события, не добавляя событие в сюжет. **Открыть карту**, Enter или двойной клик по событию открывает выбранную редакцию для работы. Предыдущая рабочая карта сохраняется в именованный черновик.

## Сохранить правку или добавить событие

**Ctrl+S** сохраняет изменения карты новой неизменяемой редакцией того же события. **Ctrl+Shift+S** позволяет добавить комментарий к редакции. Для карты без событий Ctrl+S сохраняет обычный рабочий файл. Кнопка **+ Редакция** открывает выбранное состояние для правки; результат фиксируется Ctrl+S. Время сохранения редакции не является временем события.

**+ Событие** создаёт новый момент на линии. В форме указываются название, глава, сюжетная дата, при необходимости исходная сцена и положение до/после выбранного события. Так можно сегодня добавить карту прошлого периода. **Дата и порядок** изменяет положение всего события вместе с его редакциями; исходные снимки не переписываются. Относительные даты кампании сохраняются, точный календарь не выдумывается.

Черновики и восстановление доступны через меню. Автосохранение работает каждые 15 секунд отдельно для каждой сессии. Ручная правка карты не меняет литературные сцены.

## Сравнить редакции

Кнопка **Сравнить** рядом с редакциями открывает соседнюю и выбранную редакции. Можно выбрать другие карты кнопками A и B. Доступны расположение рядом и полупрозрачное наложение, синхронные масштаб и перемещение. **Изменения** открывает список отличий; клик приближает объект. **История** возвращает экран выбора.

## Инструменты

- **V** — выбор объектов; **K** — контрольные точки политических границ; **J / P** — новая суша / государство.
- **H**, пробел или средняя кнопка — перемещение; колесо — масштаб; **Home** — вся карта.
- **R / U / Z** — маршрут / река / зона; **S / T** — символ / подпись.
- **B / E / F / I** — кисть / ластик / заливка / пипетка; **G / L / W / M** — прямоугольник / лассо / обводка / измерение.
- **Enter** завершает контур; **Esc** отменяет жест; **Ctrl+Z/Y** отменяет / повторяет до 250 действий.
- **Ctrl+C/V/D** копирует / вставляет / дублирует; **F2** открывает свойства; **F6** открывает/закрывает панель; **Tab** переводит фокус между кнопками.

Клик по имени слоя выбирает слой. Глаз управляет видимостью, замок — правкой; изоляция включается явно отдельной кнопкой. Исходные OCR-поселения, схемы и заметки доступны в архивных слоях. Основной рабочий слой мест использует полные названия карточек.

Физическая суша и государства независимы. Удаление государства оставляет землю. Захват площади разделяет соседние государства и учитывает их блокировки. «Море» разрешает политическую заливку за берегом. Общая граница использует одни узлы у обеих стран; её перемещение не меняет берег автоматически.

## Сохранение, перенос и экспорт

Переноси папку карты целиком: map.json, versions, history и assets. «Сохранить как» переносит историю и исходники. Параллельный редактор не может незаметно затереть сохранённую работу: перед записью проверяются хеши карты и каталога истории.

**tools/Atlas/Atlas-portable.zip** содержит приложение, CLI, карту со всеми цепочками, лицензии и инструкцию. После распаковки запускается Atlas.exe. Для открытия сцен и карточек выбери **Файл → Выбрать папку кампании**. Полная хроника в архив приложения не копируется.

PNG использует тот же движок, что и редактор. SVG сохраняет ID и векторную геометрию; сложное смешивание может потребовать встроенного изображения. Поддержана печать. Импорт PDN3, PNG и других растров создаёт новый проект; исходный файл не перезаписывается. Сценовые иллюстрации не генерируются.

Исходная карта предназначена ведущему. Скрытые слои остаются в файле. Персонажный экспорт через CLI создаёт только PNG и проверяет visibility, known_to и knowledge_evidence; знание ведущего не становится знанием персонажа.

## Изменения из кода

```powershell
& './tools/Atlas/bin/Atlas.Cli.exe' inspect './12_Карты/Карта_мира_Объекты' --json
& './tools/Atlas/bin/Atlas.Cli.exe' history './12_Карты/Карта_мира_Объекты' --chain main --chapter 3
& './tools/Atlas/bin/Atlas.Cli.exe' apply './12_Карты/Карта_мира_Объекты' --patch './изменение.json' --dry-run --project '.'
& './tools/Atlas/bin/Atlas.Cli.exe' validate './12_Карты/Карта_мира_Объекты' --project '.' --history
```

Патч карты содержит expected_hash из inspect и operations. Поддержаны add_layer, set_layer, set_map, set_anchor, add_feature, set_feature, delete_feature, put_node, put_arc, put_symbol, move_node, move_control, insert_control, delete_control и прежний move_border. После dry-run применяется тот же файл без этого флага.

Патч timeline использует отдельный history_hash из history. Операции set_chain и set_version меняют имена цепочек, даты, порядок и связи записей. snapshot принимает --scene, --project, --chapter, --chain, --date, --sort-date, --order, --description, --accepted. --from создаёт момент от старой версии и сохраняет текущий черновик; --checkout оставляет историческую копию открытой.

claim-country с --id и --expected-hash разделяет геометрию. Поле claim_within ограничивает новый регион исходным государством, claim_sources объединяет указанные страны. Оба служебных поля удаляются после успешного применения. --dry-run обязателен перед применением по правилам проекта.

Готовая цепочка воспроизводится через [campaign/generate.py](campaign/generate.py), профиль мест и событий — [campaign/profile.py](campaign/profile.py). Скрипт работает через публичный CLI, проверяет источники и продолжает незавершённый запуск. Он не переписывает опубликованные версии. Руководство: [campaign/README.md](campaign/README.md). Структура хранения: [FORMAT.md](FORMAT.md).

## Сборка и проверки

```powershell
& './tools/Atlas/build.ps1' -Test
& './tools/Atlas/test-editor.ps1'
& './tools/Atlas/package.ps1'
```

Сборка использует закреплённый LLVM-MinGW с проверкой SHA-256. Можно передать установленный clang++ параметром -CompilerPath. CMake поддерживает MSVC и MinGW. Хеши компилятора, исходников и обоих exe записываются в bin/build-info.json; неизменённые файлы компилируются из кеша.

Нативные регрессии проверяют хранение более 200 отмен на полной карте, вставку прошлого момента, независимость происхождения и дат, черновики, повреждённые версии, прерванную запись, конкурирующие сессии, 1000 заголовков истории, реальные сложные границы, разделение и обратное объединение государств, PNG/SVG и исходный PDN. Полный validate --history проверяет все снимки и основания.

**Проверки редактора без Computer Use:** test-editor.ps1 воспроизводит 12 сценариев через настоящие обработчики Atlas: рисование, перетаскивание, клавиатуру, диалоги, историю, редакции, сохранение и повторное открытие. Включены 360 случайных операций с проверкой отмены и повтора. Каждый сценарий работает в отдельной копии; исходная карта проверяется по хешам. Окно приложения не создаётся, системные мышь, клавиатура и буфер обмена не используются.

После запуска в .wmma/atlas-editor-tests появляется HTML-отчёт со снимками общего Direct2D-рендера, журналом действий и состоянием данных. Ошибка сохраняется вместе с шагом и документом для воспроизведения. Скрипт проверяет соответствие exe исходникам; для сборки перед тестом есть -Build. Формат сценариев и команды: [tests/README.md](tests/README.md). GitHub workflow запускает оба набора тестов, сохраняет отчёты и проверяет переносимый комплект.

Разбор прежних проблем и результаты обновления: [аудит Atlas](../../10_Обслуживание/Аудит_Atlas_2026-09-20/Обзор_и_план.md). Подробности графики: [камера и суша](performance/land-camera.md), [контрольные точки](performance/control-points.md), [реконструкция изображения](reconstruction/README.md).
