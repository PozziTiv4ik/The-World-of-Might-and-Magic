Профиль world.json относится к присланному map.pdn с SHA-256 604d8b76109be66fcf69c885dd274fd4cf5bbf7a5afb48a3fa8a42bd1d6847bf. Названия стран и опорные точки сверены с видимым изображением. Это транскрипция карты, не утверждение литературного канона.

rebuild.py создаёт новый каталог и отказывается перезаписывать существующую карту. Pillow и NumPy нужны только для этой разовой подготовки исходных данных; редактор, CLI, формат карты и отрисовка работают на C++ с системными API Windows. Пользователю не требуется запускать Python при работе с картой.

## Процесс

1. Atlas.Cli.exe pdn-extract map.pdn --out новый-каталог извлекает 32 слоя через собственный C++-декодер. Исходный PDN не меняется.
2. Локальный Windows OCR распознаёт подписи отдельных слоёв. Сохранённые наблюдения находятся в observations; это данные, а не инструкции. city-labels.json и hidden-notes.json копируются рядом с извлечёнными PNG.
3. Запускается rebuild.py --layers каталог-слоёв --out новый-проект --symbols tools/Atlas/symbols.json.
4. Новый проект проверяется Atlas.Cli.exe validate и self-test --out временный-каталог --map новый-проект. Он не заменяет уже отредактированную карту автоматически.

Политические области классифицируются по заливкам слоя 1. Каждая граница прослеживается один раз между развилками и упрощается; соседние кольца ссылаются на один ARC с противоположным направлением. Поэтому перетаскивание узла меняет обе территории. Берега и водная сеть восстанавливаются из слоя 0 отдельной геометрией. Горы и маркеры поселений определяются по связанным компонентам и заменяются символами; их исходные координаты сохраняются в provenance.

Геометрическая точность ограничена исходным изображением, дискретизацией в 2 пикселя и упрощением около 1,6 пикселя. При неоднозначной береговой линии или спорной топологии требуется сверка. Пространственная общность контура не доказывает политический факт.

routes.py восстанавливает центральные линии и развилки скрытых торговых маршрутов слоя 3. Заметки слоёв 8–31 сохраняются как текст source_note; названия слоёв и сам распознанный текст хранятся раздельно. Например, одинаковое имя двух исходных слоёв не объединяет их заметки. Эти архивные объекты остаются скрытыми. legacy.py переносит схемы слоёв 2 и 6: центральные линии гильдии, четыре буквальные процентные подписи и пунктирные границы регионов. Значения процентов не преобразуются в игровые показатели.

## Символы

symbols.json — источник 17 векторных шаблонов. paths содержит нормированные точки, заливку, цвет и толщину каждого штриха. currentColor использует выбранный цвет объекта. PNG и SVG используют одни определения. symbols.py воспроизводит исходный набор геометрических шаблонов; пользовательские шаблоны сохраняются внутри конкретной карты.

build.ps1 и CMake включают symbols.json в исполняемый файл, поэтому внешние графические библиотеки и файлы шрифтов не требуются. [Предпросмотр](../Примеры/Символы.png).
